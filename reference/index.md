# Package index

## Mapping clustered tracks

Create and save interactive maps from clusterTrack ctdf objects.

- [`map()`](https://ornitho-logics.github.io/clusterTrack.Vis/reference/map.md)
  [`save_map()`](https://ornitho-logics.github.io/clusterTrack.Vis/reference/map.md)
  : Map and save a ctdf object

## Map galleries

Build simple browsing pages and thumbnails for saved map outputs.

- [`site()`](https://ornitho-logics.github.io/clusterTrack.Vis/reference/site.md)
  : Create a Quarto index template for browsing saved maps
- [`prepare_thumbs()`](https://ornitho-logics.github.io/clusterTrack.Vis/reference/prepare_thumbs.md)
  : Prepare thumbnail cards for saved maps

## Summaries and diagnostics

Summarise clustered tracks and inspect observation timing by cluster.

- [`summarise_ctdf()`](https://ornitho-logics.github.io/clusterTrack.Vis/reference/summarise_ctdf.md)
  : Extended summary of a ctdf
- [`hist(`*`<ctdf>`*`)`](https://ornitho-logics.github.io/clusterTrack.Vis/reference/hist.ctdf.md)
  : Histogram of observation times by cluster
